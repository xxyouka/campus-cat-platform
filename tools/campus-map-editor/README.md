# 校园矢量地图编辑器

单文件 HTML 工具，产出 `campus-map.js` —— 校园猫猫小程序的校园地图底图数据。

**用法：双击 `index.html` 用浏览器打开即可**，无依赖、无需构建、无需联网。

> 放在仓库根目录的 `tools/` 下，而不是 `miniprogram/` 里 ——
> 因为 `project.config.json` 的 `miniprogramRoot` 是 `./`，小程序目录里
> 未被 `packOptions.ignore` 列出的文件都会被打进包里。

---

## 快速上手

1. 左栏先选 **校区**（本部 / 东区 / 西区 / 南区）—— 每个校区独立存档、各出一个文件
2. 把 **CAD 规划图 / 航拍图** 拖进画布（左栏「载入图片…」也行）
3. 左栏选图层 → 按 `M` 描多边形 → **双击画布结束** → 填名字 → 回车
4. 按 `P` 点一下加 POI（校门 / 食堂 / 图书馆…）
5. 顶栏 `✓ 完成并导出` → 得到该校区的底图数据（文件名见下表）
6. 放到 `miniprogram/images/campus-map/` 下对应文件名

数据自动存在浏览器 localStorage，**刷新不丢**（但底图图片不存，刷新后要重拖）。

## 校区

| 校区 | 导出文件名 |
|---|---|
| 本部 | `campus-map.js`（现有，不动） |
| 东区 | `campus-map-north.js` |
| 西区 | `campus-map-south.js` |
| 南区 | `campus-map-haizhu.js` |

- **每个校区一份草稿**（localStorage 键带校区后缀）：画东区不会覆盖本部，切回本部接着画即可。
- **底图不跟着校区走**：切校区后要重新拖入那个校区的 CAD / 航拍图（一张图对一个校区）。
- **导入自动认校区**：导入的文件写了 `campusZone`，跨校区导入会先问一句再切过去。
- 表里没有的校区名（例如导入的文件写「东区」）会按 `campus-map-<名字>.js` 临时补一条；正式加校区建议在 `ZONES` 里补一行，同时在小程序组件侧按校区加载底图。
- **小程序侧已接好**：底图登记表是 `miniprogram/utils/campusMapRegistry.js` —— 新校区导出后放进
  `miniprogram/images/campus-map/`，在那张表里加一行即可（地图页的校区切换条、详情页选点入口、
  行动分析都跟着这张表走）。

## 图层

| 图层 | 快捷键 | 基准层号 | 命名 | 建议数量 |
|---|---|---|---|---|
| 校园边界 | `V` | — | 匿名 | 1 |
| 绿地 | `G` | 0 | 匿名 | 6 |
| 运动场 | `A` | 10 | 可命名 | 4 |
| 道路 | `R` | 20 | 可命名 | 10 |
| 建筑 | `B` | 30 | 可命名 | 20 |
| POI | `P` | — | 可命名 | 10 |

**基准层号**决定默认的上下关系：绿地贴地 → 运动场 → 道路 → 建筑。
每块图元可单独调层号（见下文「层级」）。

## 快捷键

| 键 | 作用 |
|---|---|
| `V` `A` `B` `R` `G` `P` | 切换图层（边界/运动场/建筑/道路/绿地/POI） |

| 滚轮 / 空格+拖 | 缩放 / 平移 |
| `Shift` + 拖 | 平移（不误触发点击） |

## 常用操作

### 改名（四个入口）

1. 画布上**双击**图形（40px 容错，凹多边形也点得到）
2. 选中后按 `F2`
3. 左栏图元列表**双击**那一行
4. 列表那行的 `✎`

### 层级

**选中任意多边形图元**，画布底部出现调整条：

```
┌────────────────────────────────────────────────┐
│ 场内草地    层 0    [−5] [+5]  [置顶] [置底]  × │
└────────────────────────────────────────────────┘
```

场景：操场中间的草地要压在操场上面 → 选那块**绿地** → 按 `+5` 两次（0 → 15，超过运动场的 10）。

层号写进 JSON 的 `f.z`，重新导入不丢。

### 找不到图元

- 列表每行的 **`◎`** = 把视图移过去并放大居中
- `F4` = 定位当前选中
- 右上角**缩略图**可点，点击跳转
- 画完的图元如果一半以上在画面外，会**自动定位**并提示

### 只看底图描线

左栏图层行的**眼睛图标**可临时隐藏图层，方便对着原图描边。

## 输出格式

```jsonc
{
  "campusZone": "本部",          // 与小程序校区同一套写法：本部 / 东区 / 西区 / 南区
  "mapVersion": 1,
  "imageSize": [1580, 840],      // 底稿原图像素，仅用于换算
  "bounds":   [[x,y], ...],      // 校园边界，闭合多边形
  "buildings":[{ "name":"新图书馆", "kind":"library", "p":[[x,y],...] }],
  "sports":   [{ "name":"操场", "p":[[x,y],...], "z":15 }],
  "roads":    [{ "name":"主干道", "kind":"main", "p":[[x,y],...] }],
  "greens":   [{ "p":[[x,y],...], "z":15 }],        // 匿名，无 name
  "pois":     [{ "name":"南校门", "kind":"gate", "x":300, "y":760 }]
}
```

坐标为**底图像素**，原点左上、x 右 y 下，运行时除以 `imageSize` 归一化。

### kind 枚举

| 字段 | 取值 |
|---|---|
| `buildings.kind` | `teaching` `dorm` `library` `canteen` `office` `lab` `training` `other` |
| `roads.kind` | `main` `branch` `path` |
| `pois.kind` | `gate` `canteen` `library` `teaching` `dorm` `sport` `parking` `other` |

---

## 精度要求

**误差 5~10 px 足够**（1580px 宽约 0.6%）。相对位置对就行，不要抠绝对精确。

超过范围的点会实时提示「N/M 个点在校园边界外」；边线交叉会提示「自相交」。

---

## 注意事项

- 底图图片**不会**被保存（localStorage 存不下），刷新后要重拖，但图元数据不丢
- 导出的文件首次导入时会被自动清洗：去掉闭合重复末点、按名称修正 `kind`
- 导入同时吃 `.json` 与 `.js`（`.js` 会剥掉 `module.exports` 包装），所以早期导出的 JSON 也能直接拖回来
- 别把这个文件放进 `miniprogram/` 目录，会被打进小程序包里
